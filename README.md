# SAEIS - Smart Audit & ERP Integration System

نظام ذكي لأتمتة أعمال التدقيق المحاسبي المتقدم والربط البرمجي المباشر مع أنظمة إدارة الموارد (ERP Systems).

---

## 📌 عن المشروع
يهدف مشروع **SAEIS** إلى تقديم حلول رقمية مجدية في التحليل والتدقيق المالي، والربط الذكي للبيانات المالية بين الأنظمة المختلفة لضمان أعلى مستويات الدقة والامتثال للمعاير المالية.

---

## 📁 محتويات المستودع
- `fix_names.py`: سكربت معالجة وتنظيف بيانات الحسابات والأسماء.
- `package.json` & `pnpm-lock.yaml`: إعدادات وبيئة التشغيل والاعتماديات البرمجية.
- `SAEIS Smart Audit Pitch Deck.pdf`: العرض التقديمي للمشروع.
- `SAEIS_5Year_Financial_Model.xlsx`: النموذج المالي والتوقعات لمدة 5 سنوات.
- `SAEIS_Smart_Audit_&_ERP_Integration_System.pdf`: التوثيق التفصيلي لمشروع الربط والتدقيق الذكي.
